Análisis Interactivo de Eficacia de la Capacitación

Hallazgos y Resultados del Proceso de Medición (Período 2024-2025)

Hallazgo Clave del Proceso

Falta de Respuesta

El uso frecuente del procedimiento para registrar "eficacia" ante la falta de respuesta del evaluador, indica que el método de recolección de datos primario requiere mejora.

Tasa de Respuesta (Jefes)

<50%

Promedio de respuesta, por debajo del 80% definido como umbral para una muestra válida. Este resultado activa el procedimiento alternativo.

Fortaleza del Contenido

>90%

Percepción positiva de aplicabilidad en las pocas encuestas respondidas, demostrando que el contenido de los cursos es útil y valorado.

Oportunidad de Mejora

Evaluación al Discente

La migración de la evaluación hacia el participante es una tendencia positiva y una vía viable para obtener datos reales y fiables, reduciendo la dependencia del criterio por falta de respuesta.

Análisis Global Detallado

Síntesis de Observaciones del Proceso de Medición

  • Aplicación de Procedimiento por Falta de Respuesta: Se observa el uso recurrente de un criterio aprobado (Oficio 904-2022/AFAR) que permite registrar la eficacia cuando el responsable de la evaluación (jefe) no responde. Su uso frecuente es un resultado medible que indica una debilidad en el mecanismo de recolección de datos.
  • Incumplimiento del Umbral de Muestra Válida: La tasa de respuesta de supervisores (promedio <50%) no alcanza el 80% establecido (Oficio 16-2021/GGQJ/AGCP) para asegurar la representatividad de los datos. Este es el evento que activa el uso del procedimiento alternativo.
  • Potencial en la Evaluación al Participante: Se identifica una tendencia positiva en migrar la evaluación hacia el participante (discente), lo cual representa la oportunidad más clara para obtener datos fiables y mejorar el proceso.
  • Criterios de Exclusión Definidos: El SGC ha definido de manera deliberada no medir la eficacia de cursos cortos (Memorando 5-2022/AFAR), lo que demuestra un enfoque selectivo y gestionado en la aplicación de este proceso, lo que constituye una buena práctica.

Síntesis de Conclusiones y Resultados del Proceso

  • El Proceso de Medición Requiere Mejora: El hallazgo principal es que el proceso de evaluación de eficacia, tal como está diseñado, no está generando la data necesaria para un análisis profundo. La dependencia en el procedimiento que se aplica por falta de respuesta del evaluador cumple con cerrar administrativamente los expedientes, pero no con el objetivo técnico de medir el impacto para la mejora continua. El resultado del proceso actual es la falta de evidencia, no la confirmación de la eficacia.
  • Contenidos de Calidad con Medición Deficiente: Los datos parciales obtenidos sugieren que los cursos son de alto valor para quienes los toman. Esto crea una paradoja positiva: la calidad del contenido es alta, lo que justifica la inversión en mejorar su sistema de medición para poder demostrarlo formalmente.

Propuesta Mejorada para la Evaluación de Eficacia de la Formación

Con base en los hallazgos, el objetivo principal debe ser fortalecer el mecanismo de recolección de datos para que la aplicación del procedimiento por falta de respuesta se convierta en una rara excepción. Se detalla a continuación una propuesta de proceso rediseñado:

1. Rediseño del Proceso de Evaluación (Enfoque en el Discente)

1.1. Desarrollo de Evaluaciones Diagnósticas (Pre y Post): Crear un par de evaluaciones (pre-test y post-test) para cada curso, diseñadas para medir objetivamente el incremento en el conocimiento o habilidades alineadas a los objetivos de aprendizaje.

1.2. Implementación Obligatoria: Administrar el pre-test como requisito para iniciar el curso y el post-test (junto a una encuesta de satisfacción) como requisito indispensable para la emisión de la constancia. Esto garantiza una tasa de respuesta cercana al 100% por parte del discente, eliminando el problema de la falta de datos.

2. Rol Facilitador de la Red Docente

Capacitar a la red docente para que actúen como facilitadores activos del proceso, guiando a los discentes y reforzando la importancia y obligatoriedad de completar las evaluaciones para obtener su acreditación.

3. Análisis y Utilización de Datos para la Mejora Continua

Utilizar la comparación entre los resultados del pre y post-test para obtener una métrica clara de la eficacia. Analizar los datos de satisfacción para mejorar el diseño de los cursos y generar informes periódicos que retroalimenten a los diseñadores de contenido y docentes.

4. Sistematización y Automatización (Acción Estratégica)

4.1. Solicitud de un "Módulo de Evaluación de Eficacia": Para asegurar la sostenibilidad y eficiencia de este nuevo proceso, se propone gestionar y solicitar formalmente la inclusión de un **"Módulo de Evaluación de Eficacia"** como un componente integral del nuevo **Sistema de Registro y Control Académico** que actualmente se encuentra en desarrollo.

  • Funcionalidad Clave: Este módulo deberá permitir la creación y asignación de pre y post-tests, automatizar el control de su completitud como requisito para avanzar y generar reportes comparativos automáticos.
  • Beneficios: La integración con el sistema académico centralizará la información, reducirá la carga administrativa, mejorará la experiencia del usuario y garantizará la recolección sistemática de datos de alta calidad para la toma de decisiones.
